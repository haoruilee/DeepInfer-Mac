\section{Related work}
\label{sec:related}
\paragraph{Running models larger than memory.} FlexGen offloads weights, activations and the KV cache to CPU memory and disk, and searches for a schedule that maximizes throughput for large batches \citep{flexgen}. LLM in a Flash keeps weights in flash storage and loads only the rows that predicted-active neurons need, reading them in large chunks \citep{llmflash}. PowerInfer keeps frequently activated neurons on the GPU and computes the rest on the CPU \citep{powerinfer}, and llama.cpp memory-maps quantized weights and leaves residency to the operating system \citep{llamacpp}. For mixture-of-experts models, \citet{moeoffload} combine an LRU expert cache with speculative loading of the next layer's experts on consumer GPUs, and our predictor is theirs. Pre-gated MoE changes the model so that each layer selects the next layer's experts \citep{pregated}. MoE-Infinity and ProMoE prefetch and cache experts based on activation statistics \citep{moeinfinity,promoe}, and AdapMoE adapts gating and prefetching to the cache \citep{adapmoe}. Fiddler computes experts on the CPU instead of moving them \citep{fiddler}, MoE-Lightning pipelines CPU and GPU work for large batches \citep{moelightning}, and EdgeMoE and PowerInfer-2 bring expert or neuron offloading to phones \citep{edgemoe,powerinfer2}. Our setting differs from most of these in two ways. The dense part of the model alone takes a third of the memory, and the workload is a single interactive sequence. Under these conditions our measurements favour a fixed set of cache slots, filled by reads that bypass the page cache, over operating-system caching or eager prefetching.

\paragraph{Prefetch control.} Giving demand requests priority over prefetches, and inserting prefetched data with low priority, are established techniques in processor memory systems \citep{padc,fdp,qureshi2007}. Idle-window speculation applies both ideas to expert reads from an SSD. Our contribution there is the measurement showing why naive expert prefetching loses on a memory-bound laptop, and the finding that ordering, not cache pollution, is the part that matters.

\paragraph{Expert parallelism.} DeepSeek's serving stack spreads experts over many GPUs, overlaps the all-to-all communication with computation using two micro-batches, and replicates heavily used experts \citep{deepseekv3,deepinfer}. We map these ideas to a single GPU and SSD and measure which of them still apply.

\paragraph{DeepSeek-V4 models on Apple silicon.} Several community projects run DeepSeek-V4-generation models on Macs, and we learned from all of them. ds4 is a dedicated C and Metal engine whose API-sampled test vectors we use for evaluation \citep{ds4}, flash-moe streams experts from the SSD in C and Metal \citep{flashmoe}, and two MLX ports target V4-Flash and V4.1-Flash \citep{ssdmoe,pipenetwork}. \method{} differs in following the official reference implementation operation by operation, which lets us test against it, and in sharing its forward path and serving interface with DeepInfer \citep{deepinfer} and deepseek-recipe \citep{deepseekrecipe}.

\paragraph{Quantization.} Post-training methods such as GPTQ lower weight precision with second-order error correction \citep{gptq}. We use a simpler per-group clipping search, because the converter streams each expert from the network once and has no calibration pass. Instead we choose the precision of each layer separately and keep the dense weights lossless.

\paragraph{Sparse-attention indexers.} DeepSeek Sparse Attention selects keys with a light multi-head indexer \citep{deepseek32}. V4.1-Flash adds key compression and a two-level candidate selection \citep{deepseek41flash}, and IndexCache reuses indices across layers \citep{indexcache}. Several methods speed up the selection while keeping the full scorer's output. GVR checks a predicted threshold during decoding \citep{gvr}, LiteTopK fuses scoring with candidate filtering \citep{litetopk}, and DoSA drops keys using score bounds \citep{dosa}, following the MaxScore and WAND idea from document retrieval \citep{maxscore1995,wand2003}. MISA screens with a subset of heads but does not guarantee the full scorer's selection \citep{misa}.
